## Differentiation Formulae
When we're finding the derivative of a function, it is almost never going to be in the simple 
form f(x). Because of this we need to know what to do when things break away from the norm like 
f(x)/g(x) or f(x)g(x). This material is also covered in the basics video but I
added it here because we need to be able to prove them...
