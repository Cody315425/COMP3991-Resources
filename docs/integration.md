Integration is the reverse of differentiation we use it to find the area below a curve. In machine learning integration is not used very often but it's good to understand how it works for those edge cases.

## Riemann Sum
This was the first approach to finding the area below a curve. It uses rectangles (their area is very easy to calculate) to estimate the area beneath the curve. The thinner these rectangles are the better the estimate becomes. Therefore, if we introduce limits we can calculate the area as the width of the rectangles approach zero!
